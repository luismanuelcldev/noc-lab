Objetivo sintetico de sondeo

Este servicio existe para que las sondas de blackbox tengan un objetivo real que comprobar. No ejecuta logica de negocio.

Por que existe esta pagina

La sonda http_canary de blackbox-exporter no solo valida el codigo HTTP: tambien comprueba que el cuerpo contiene el texto noc-canary-ok. Si alguien sustituye el contenido por una pagina de mantenimiento, esa comprobacion falla y la alerta salta aunque el puerto siga respondiendo 200.

Como parar el servicio para ver una alerta

  • docker compose stop demo-app → ServicioCaido + PuertoTCPInaccesible
  • docker compose start demo-app → la alerta se resuelve en el siguiente ciclo de evaluacion

noc-canary-ok
